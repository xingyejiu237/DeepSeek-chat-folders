# tempermonkey-scripts

个人 Tampermonkey 用户脚本合集，增强网页功能体验。

## 脚本列表

### DeepSeek 文件夹增强

为 [DeepSeek Chat](https://chat.deepseek.com) 的侧边栏添加会话文件夹管理功能。

**功能特性：**

- 创建/删除自定义文件夹，将会话分类管理
- **多选批处理** — 勾选多个会话，一键移入目标文件夹
- **双层优雅布局** — 操作按钮与文件夹 Tab 分两行排列，告别拥挤
- 右键菜单 / 悬浮按钮快捷移入文件夹
- 按文件夹筛选会话列表，无闪烁流畅切换
- 日期标题自动跟随筛选结果联动
- 导入/导出文件夹配置，方便备份与迁移
- 自动适配 DeepSeek 深色/浅色模式

## 使用方式

1. 安装 [Tampermonkey](https://www.tampermonkey.net/) 浏览器扩展
2. 点击 `DeepSeek.user.js` 文件，Tampermonkey 会自动识别并打开安装页面
3. 点击「安装」，访问 [DeepSeek Chat](https://chat.deepseek.com) 即可使用
